# Flicksense — Notes

**Flicksense** is an Angular 17 single-page application that lets authenticated users discover and review movies by integrating with The Movie Database (TMDB) API. The frontend handles user registration, login, and logout against a local Node.js backend (`localhost:3000`) using JWT-based authentication (tokens stored and decoded via `TokenStorageService`), and an `AuthGuard` protects the home route from unauthenticated access. Once logged in, users can browse popular movies, filter discoveries by genre and release year, and submit reviews through a dialog component — all rendered with Angular Material and VMware Clarity UI components. The app uses lazy-loaded standalone components for each route (`home`, `login`, `register`, `users`, `profile/:id`, `messages`) and relies on RxJS observables throughout the service layer for async data handling. A TMDB API key must be supplied via `src/environments/environment.ts` for local development.
